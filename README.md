Практична робота №4
Ігри з природою

Програма реалізована мовою C# та призначена для пошуку оптимальних стратегій у задачах «ігри з природою».

Реалізовані критерії
критерій Вальда;
критерій оптимізму;
критерій Гурвіца;
критерій Севіджа;
критерій Байєса;
критерій Лапласа.
Можливості програми
введення матриці вручну;
завантаження тестових прикладів;
підтримка довільних розмірів матриці;
покроковий протокол обчислень;
визначення всіх оптимальних стратегій;
пошук стратегії, що найчастіше була оптимальною.
Технології
C#
.NET Console Application
Visual Studio
